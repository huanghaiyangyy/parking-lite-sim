# 场景材质与占位锥桶

当前默认 `render.material_style: realistic`、`render.lighting_style: simple`，作用于概览、四路鱼眼及其生成的视频。
不改变相机 K/D、外参、原场景几何、车辆运动及编码参数。

- 墙面：暖灰混凝土、2.4 m × 1.2 m 模板接缝、表面色差、墙脚污渍。
- 沥青：较暗的中性灰、细颗粒和轻微斑驳。
- 路沿：保留资产约 16.5 cm 的立面和原倒角，增加混凝土质感、1 m 接缝及侧面明暗。
- 光照：默认只计算环境光和漫反射方向光，关闭动态投影、锥桶高光及远景雾效；保留表面朝向的明暗差。`lighting_style: shadowed` 可恢复完整光照：1536² 几何阴影图、四次采样软化边缘、锥桶高光和远景雾效；车辆位姿变化时更新阴影，静止时复用。
- 锥桶：在 map 场景两个空车位内各放两只。每只 70 cm 高，40 cm 橡胶底座，橙色锥身和两道白色反光带；按路面实际高度放置。四个 GL 坐标为 `(2.8, 0.55)`、`(2.8, 1.55)`、`(-3.7, 7.85)`、`(-3.7, 8.85)`，此处分别为 X/Z。中央左侧空车位保留。

纹理按世界坐标和米制尺寸采样，相机移动时固定于物体；固定随机种子生成的 256² 纹理带 mipmap，减少远处闪烁。不需要下载外部模型或添加依赖。

在 YAML 中设置原有模式：

```yaml
render:
  material_style: flat
```

`flat` 保留原始光照/颜色，但仍显示新增锥桶。启动前设 `LOT_SLOT_CONES=0` 可以禁用新增的四只占位锥桶。

## 渲染耗时优化

默认配置等效于：

```yaml
render:
  material_style: realistic
  lighting_style: simple
  pinhole_sample_mask: true
```

KB 鱼眼重映射会跳过大量宽角针孔源像素。根据 K/D 的 LUT，提前缓存实际会被双线性插值读取的四邻域，并保留完整 2×2 像素组供纹理导数计算；片元着色器跳过其余像素的材质/光照计算。`pinhole_sample_mask: false` 可关闭此优化。普通针孔概览、CPU 源图、旧等距鱼眼及 `flat` 模式不使用该遮罩。每组不同 K/D 在默认 4× 内部采样下额外占用约 19.7 MB 遮罩纹理，相同 K/D 共用。

TX2 同一 GL 上下文交替测量，每模式 25 帧有效样本，四路 1280×960、内部 4×、RGBA 读回，移动位姿下两种完整光照模式均独立更新阴影：

| 模式 | 中位耗时 | P95 |
| --- | ---: | ---: |
| 原始纯色 `flat` | 52.1 ms | 53.2 ms |
| 增强材质＋完整光照，无遮罩 | 89.6 ms | 91.1 ms |
| 增强材质＋完整光照，有遮罩 | 66.9 ms | 68.3 ms |
| 增强材质＋简单光照，无遮罩 | 65.5 ms | 66.9 ms |
| 当前默认：增强材质＋简单光照＋遮罩 | 53.4 ms | 54.3 ms |

当前默认比完整增强版减少约 40.4% 耗时；在已有遮罩优化上再简化光照，减少约 20.2%。不降低分辨率、内部采样倍率或纹理细节。测试不包含编码/传输，现有主仿真同时运行，不能等同于完整链路帧率；不同批次时钟和负载也会影响绝对值。

两种光照各四个位姿在 TX2 及本机验证遮罩开关前后 RGBA 逐像素一致。TX2 GPU/OpenCV 映射随机源图、两组 K/D、四个位姿和相机顺序检查通过。桌面 AMD/Mesa 的独立场景重绘与 CPU 对比出现少数最大 1 灰阶差；同一源图的重映射和遮罩开关比较均精确一致，未放宽原检查断言。尚未验证 APA 召回率。

可复测：

```bash
rtk proxy env -u DISPLAY /path/to/sim-python scripts/check_render_cost.py --frames 25 --capture-scale 4 --out output/render-cost.json
```

本次板端验证在 `/tmp/tx2-materials-20261019`，没有切换 TX2 主运行目录或重启当前视频/CAN 进程。

模型仍读取现有 Nx9 `.bin`，在上传 GPU 时补材质 ID，因此本次不需要重建缓存。材质 ID 从已有颜色恢复；以后若改资产配色或不同类型共用颜色，应改为在缓存中明确保存材质 ID。原资产和运行时增加的锥桶不会重复写回缓存。

验证和导出同视角对比：

```bash
rtk proxy env -u DISPLAY /path/to/sim-python scripts/check_materials.py --out output/materials --capture-scale 4 --frames 6
```

输出墙体、路沿、锥桶、概览、AVM 对比图、四路鱼眼图及 `checks.json`；检查原模型顶点未改变、四只锥桶尺寸/朝向、材质分配、静止画面一致性及移动时渲染耗时。加 `--lighting-style shadowed` 可导出完整光照模式。这里的 AVM 为仿真器自带 IPM 拼接预览，不是板端原厂 AVM。

该版本增强视觉线索；真实感知模型的墙体、路沿和锥桶召回率仍需板端同帧语义输出验证。合成材质不是实拍贴图，锥桶没有接入碰撞或仿真超声测距。可选完整光照的阴影覆盖以本车为中心附近约 48 m 的光源视锥，远景不会保留全部投影阴影。
